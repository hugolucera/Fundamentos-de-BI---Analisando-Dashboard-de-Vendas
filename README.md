Projeto Power BI – Análise de Dados

Projeto desenvolvido durante o desafio da DIO com o objetivo de praticar a criação e análise de dados utilizando o Power BI.

Foram reproduzidas páginas do projeto apresentado no curso e criada uma terceira página com novos visuais, incluindo:

Mapas com vendas, unidades vendidas e lucro por país;
Gráfico de pizza com lucro por segmento;
Organização e personalização dos visuais;
Configuração de títulos e dicas de ferramentas.

O projeto teve como foco desenvolver conhecimentos em visualização de dados, criação de dashboards e análise de informações utilizando o Power BI.
